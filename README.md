# Tesliuk Tetiana — фотосайт

Статический сайт. Никакой сборки: открывается как есть, заливается на любой хостинг
(Netlify, Vercel, GitHub Pages, обычный ftp) — просто кидаешь папку целиком.

## Деплой на Netlify

Сборки нет — Netlify просто раздаёт папку. Настройки уже лежат в `netlify.toml`.

### Способ 1 — перетащить папку (быстрее всего, без аккаунта в git)

1. Открыть https://app.netlify.com/drop
2. Перетащить туда папку `tesliuk-photo` целиком (или архив `tesliuk-photo.zip`)
3. Сайт поднимется через несколько секунд на адресе вида
   `https://random-name-123.netlify.app`
4. Site configuration → Change site name — поменять адрес на человеческий

Чтобы обновить сайт потом — перетащить папку туда же ещё раз.

### Способ 2 — через командную строку

```
npm install -g netlify-cli
cd tesliuk-photo
netlify deploy --prod
```

Первый запуск спросит про логин и предложит создать новый сайт.
Дальше каждое обновление — та же одна команда.

### Способ 3 — через git (лучший, если правки будут регулярно)

Залить папку в репозиторий на GitHub, в Netlify нажать
Add new site → Import an existing project, выбрать репозиторий.
Build command оставить пустым, publish directory — точка (`.`).
После этого каждый `git push` сам обновляет сайт.

### Что поправить сразу после первого деплоя

Netlify выдаст адрес сайта. Его нужно прописать в трёх файлах —
от этого зависят превью ссылок в мессенджерах и индексация в поиске:

```
cd tesliuk-photo
grep -rl "tesliuk-tetiana.netlify.app" . | xargs sed -i '' "s|https://tesliuk-tetiana.netlify.app|https://НОВЫЙ-АДРЕС|g"
```

(меняется в `*.html`, `robots.txt` и `sitemap.xml`)

### Свой домен

Domain management → Add a domain. Netlify сам выпустит
бесплатный SSL-сертификат. После этого ещё раз прогнать команду выше
уже с новым доменом.

### Что уже настроено

- `netlify.toml` — html и тексты сайта отдаются без кеша (правки видны сразу),
  фотографии кешируются на год, плюс базовые заголовки безопасности
- `404.html` — страница «не найдено» в стиле сайта
- `favicon.svg` — иконка во вкладке
- `robots.txt` и `sitemap.xml` — для поисковиков
- Open Graph и Twitter Card — при отправке ссылки в телеграм или инстаграм
  подтягивается обложка, заголовок и описание

## Два языка: українська и English

Сайт один, версии переключаются на лету — без перезагрузки и без второй папки.
Кнопки `UA | EN` стоят рядом с иконкой инстаграма (десктоп) и рядом с бургером
(телефон). Выбор запоминается в браузере и действует на всех страницах.

- Язык по умолчанию — `defaultLang` в начале `data.js` (сейчас `"uk"`).
- Можно открыть страницу сразу на нужном языке: `?lang=en` или `?lang=uk`.
- Все тексты лежат в `data.js` в блоке `i18n`: `uk` и `en` — два одинаковых
  по структуре словаря. Правишь текст — правь в обоих.
- Структура (фото, пропорции, раскладка коллажа, slug проектов) общая
  и от языка не зависит.

Чтобы добавить третий язык: скопируй блок `uk`, переименуй, переведи,
и допиши его код в массив `LANGS` в начале `main.js`.

## Где что менять

Весь контент — в одном файле: **`assets/js/data.js`**.
Там имя, тексты, контакты, список проектов и пути к фотографиям. HTML трогать не нужно.

## Первый экран — плывущий коллаж

Лента карточек едет по кругу бесконечно и не останавливается.
При наведении карточка поворачивается в 3D вслед за мышкой,
продолжая ехать вместе с лентой.

Раскладка задаётся массивом `hero` в `data.js`. У каждой карточки:

- `src` — путь к фото (файлы лежат в `images/hero/`)
- `x` — отступ слева в процентах ширины экрана
- `w` — ширина в процентах ширины экрана
- `t` — отступ сверху в процентах высоты экрана, можно отрицательный
  (тогда карточка подрезается верхним краем)
- `ratio` — пропорция кадра: `"3/2"`, `"4/3"`, `"16/9"`

Блок раскладки шириной в один экран повторяется по кругу — шва не видно.
Все кадры идут под заголовком. На телефоне та же раскладка, увеличенная
множителем `--k` в css.

## Чего пока не хватает

- `images/about.jpg` — портрет Тетяни на странице About (сейчас заглушка)
- кадры внутри проектов: сейчас в каждом проекте 1–2 фото,
  те же, что на первом экране. Как добавить — ниже.

## Как добавить фотографии

1. Клади файлы в `images/racing/`, `images/automotive/` или `images/commerce/`.
2. В `data.js` у проекта пропиши путь в `cover` и в массив `images`.
3. `ratio` — пропорция кадра: `"portrait"` (вертикаль, по умолчанию),
   `"landscape"` (горизонталь, раскрывается на всю ширину) или `"square"`.

Пока файла нет — на его месте аккуратная заглушка, сайт не ломается.

**Подготовка файлов:** длинная сторона ~2000 px, JPEG качество 80,
вес до ~400 КБ на кадр. Обложки проектов — вертикальные.

## Страницы

- `index.html` — главная: имя, сетка работ с фильтром по категориям, услуги
- `project.html?p=slug` — страница проекта (одна на все, собирается из `data.js`)
- `about.html` — о фотографе
- `contact.html` — контакты и форма

## Форма обратной связи

Сейчас форма открывает почтовый клиент с заполненным письмом (бэкенда нет).
Если нужна отправка на сервер — подключается Formspree/Getform за пять минут.

```bash
python3 -m http.server 4317
```
Потом открыть http://localhost:4317
